飞书弹幕 · 0.7.1

打开 飞书弹幕。当前仅你本人可用。网页管理授权与设置，这台 Mac 的本机组件负责让弹幕飘过桌面。

开始使用

  1. 打开网页，点击“连接桌面组件”。浏览器询问本地网络权限时，由你允许。
  2. 飞书只读授权成功后自动接收。已有有效授权时，打开网页自动恢复；如果你主动点过“停止接收”，仍保持停止，点击“开始接收”恢复。
  3. “桌面试播”发送一条短暂的透明弹幕，不创建测试背景。“暂停展示”保留阅读位置；“停止接收”停止读取并清空弹幕。

接入 Agent

点击页头的“接入 Agent”，把复制的内容发给这台电脑上的 Agent，再直接描述你要的外观。无需填写需求框或贴回 JSON。连接 30 分钟内有效，网页保持打开；Agent 修改后会自动保存到你的个人外观。只有 Agent 确认 saved=true 才代表保存完成。复制内容含临时外观连接密钥，不要发到群里。

Agent 只能读取和修改皮肤颜色、字号、圆角、网页布局、历史显示与短消息动效。接收、授权、过滤和部署由维护者统一管理。这个入口不内置模型，也无法让云端 Agent 直接访问你的本机。

跟随飞书启动

这台 Mac 的登录项观察飞书程序启动事件，自动打开网页并连接桌面组件。它不检查飞书内部账号登录；飞书未退出而只切换账号时，不保证再次触发。关闭所有网页后，约 2 分钟内停止读取并清空消息内存。停用联动可运行 scripts/web-autostart.sh --disable，恢复则不带参数运行。

消息与隐私

仅显示开始接收后、确认未读的新消息。默认跳过免打扰会话，屏蔽优先。不发送消息、不修改已读状态、不读取飞书内部数据库。消息正文、历史与去重只在内存；授权配置和个人设置按中台账号隔离保存。桌面层透明、鼠标穿透、不抢键盘焦点。

验证边界

Web 自动检查 14 项通过，覆盖身份隔离、只读筛选、分页、去重、重连、自动接收、停止偏好和外观限制。本机 MCP 的协议、字段限制、短期授权及保存确认已有合成测试。实际网页与本机联动验收结果以本次交付说明为准；上述检查不能替代真实飞书新消息与多日运行验收。
