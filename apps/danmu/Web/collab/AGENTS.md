# 双人协作面板
- /collab 独立于弹幕接收；只保存需求、开发记录、版本摘要、审批及发布状态，不读取飞书消息。
- 中台稳定用户 ID 鉴权；COLLAB_OWNER_ID 仅指定首次身份绑定人；宰治与柚子均为共同项目负责人，第二人本人申请并经既有负责人核对后获得相同项目权限。显示名不授予权限。最多两人。
- 审批绑定版本摘要、代码 SHA 与基准 SHA。内容变化清空审批。两位不同成员批准、检查通过、在线发布助手复核后才能更新 GitHub 源码。
- Agent / 发布助手只能同步版本与执行已批准的发布，不能替人同意。GitHub 凭证留在本人电脑，不传给服务器。
- COLLAB_PREVIEW=1 仅限本地；生产禁止。测试用独立临时目录和合成 GitHub 数据，不发真实 Release、不合并 PR。
- 持久数据写 /data/collab；不自动替换应用、不改登录项或 48763。
- node --test collab/*.test.cjs；浏览器检查需求提交、双方审批、内容变化撤销、窄屏与深色。

- 版本 target 固定 github-source；旧 target=both 的待确认版本撤销审批并重新核对，不触发安装包与网站部署。项目来源补录幂等，actor 为项目来源补录，贡献者另列，不追溯伪造时间。
