# 网页版飞书弹幕
- Node 原生 HTTP 服务，public 为中台风格界面，core 复用 Desktop 已有只读 Reader 与消息分页。
- npm test 验证认证边界、合成接收与呈现；npm start 本地启动，正式发布仅 virxact MCP。
- 中台身份头识别用户，飞书授权按用户 profile 隔离；禁止打包任何本机凭证、真实消息或日志。
- 用户已于 2026-10-14 同意公司服务器临时处理本人消息。正文、去重、历史只在内存，官方 CLI 授权配置写 /data，权限 0700。仅本人可用。
- 不发送消息，不标记已读，不用机器人事件替代用户身份消息读取。真实消息接收需要用户自行授权后验收。

- 0.6.0：个人外观 JSON 只能通过 public/appearance-schema.js 白名单验证，服务端再次验证；禁止让 Agent 入口执行任意代码或修改核心。停止偏好与外观可持久化，正文和历史仍只在内存。授权完成自动开始；停止状态优先于正在完成的授权。

- 0.7.1：Agent 卡片、输入与 JSON 导入界面已移除，页头只保留“接入 Agent”。按钮复制独立的本机外观 MCP 短期连接，不能复制桌面消息桥接 nonce。外观状态由 PersonalAppearance 管理；desktop.js 仅本机每 2 秒同步 Agent 外观，服务端再次白名单校验，成功后 ACK。外观服务不提供消息或核心设置工具。不得为测试添加遮挡桌面的不透明全屏背景。
