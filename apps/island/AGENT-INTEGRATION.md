# 共同版接入说明

0.8.0 build35 的入口在普通工作台“Agent 与皮肤”。状态监测默认关闭，开启后只读取选中的来源，换皮肤不要求监测。日常 AI 派单继续由原 Workspace 队列处理，监测不会自动建立 Codex 对话或取代 Dot 连接。当前共同版只做了合成回归，没有读取本机真实 Agent 记录。

下文是柚子独立版的历史接入与现场验证。旧网页入口、偏好域与“已实测”只适用于原开发环境，不代表共同候选版验收。

# Agent状态与额度（0.6.3）

在回滚后的0.5.0上新增独立Agent模块，保留原飞书消息功能。范围为Codex、Claude桌面版的Code功能、WorkBuddy。

## 使用

从岛左上角模块入口选择“Agent状态”，点击Codex或WorkBuddy设为主用。也可以在网页设置的“Agent状态”页面切换，并设置完成提醒、额度提醒。

- 红灯：本机有任务正在工作。
- 绿灯：本轮任务已完成；只提醒本次监测期间新发生的任务完成，启动时不补弹历史任务。完成时自动露出第二阶段胶囊，在右侧显示绿灯、“已完成”和勾号，停留约5秒后收回。复用原状态胶囊，不另弹“Agent提醒”卡片；点击可查看完成来源的Agent详情。
- 完成提示只有一次光晕与勾号描画；关闭动态或启用系统减少动态时使用静态提示。
- 橙灯：等待操作或任务中断。灰灯：尚无可靠数据或状态超过15分钟未更新。
- 并行任务中只完成一个时，会提示该任务完成；还有任务工作时保持红灯。
- 额度每3分钟查询一次，可以主动刷新。显示剩余比例、实际返回的额度周期、重置时间或可用积分。
- 剩余严格低于20%时在岛上提醒；同一重置周期只提醒一次。无重置时间的积分池回升到20%以上后，再次跌破时重新提醒。

## 自定义显示

网页设置顶部的“显示哪些Agent”支持任选一个、两个或三个，勾选后自动保存。“仅显示主用”只保留当前主用，“显示全部”恢复三项。至少保留一项；隐藏当前主用时自动切换至仍显示的第一个Agent。

网页卡片、原生岛切换栏和提醒范围保持一致。仅显示一个时不显示岛内切换栏；隐藏不删除接入配置和历史额度数据，重新勾选即可显示。设置存入原有Agent独立偏好；旧版缺少显示列表时按全部显示迁移，保留原有主用和提醒开关。

图标来自本机已安装的Codex/OpenAI、Claude、WorkBuddy应用包，仅用于标识对应接入。PNG资源随应用打包，无需访问外部图片服务。

## 接入状态与边界

| Agent | 数据来源 | 当前验收范围 |
| --- | --- | --- |
| Codex | 本机JSONL任务事件；官方app-server的account/rateLimits/read | 真实账号额度、当前工作状态已读取；日志增量和完成提醒已做隔离场景测试 |
| WorkBuddy 5.9.0 | 本机只读任务数据库；已登录客户端的本机认证IPC积分查询 | 真实任务记录、真实积分已读取；任务数据库开始/完成/中断及账号隔离已做隔离场景测试；未为验收发起消耗积分的AI任务 |
| Claude桌面版 | 桌面plan-usage-history.json用量缓存 | **未完成接入**：目前没有可用的登录账号。仅预留入口和缓存读取，尚未完成桌面任务状态与实时额度的真实联调，不宣称可用 |

Codex只显示账号实际返回的周期；没有5小时窗口时不补造5小时额度。WorkBuddy用积分余额除以积分组总额度，既显示百分比，也显示绝对积分；不会把单次会话消耗或Packages重复累计。订阅上下文长度不能替代账号额度。

Claude恢复接入需要用户能够合法登录的桌面账号，以及真实的任务开始、完成、取消、等待授权和额度样本；拿到样本后仍需补齐适配和验收。不能仅凭登录就认为本版本会自动支持全部功能。

当前只监测这台Mac留下的任务数据。客户端更新可能改变本机格式；读取失败显示原因并保留上次记录及时间，过期数据不触发额度告警。没有消费速度依据，未加入“预计耗尽”预测。

## 实现与检查

`Sources/IslandShell/Agents/`包含三个适配入口、状态模型、去重提醒和原生面板；`SettingsWeb/dist/`提供桌面设置页面。设置单独存放在`local.youzi.island.agents`，不覆盖飞书配置。查询不创建AI任务，不保存提示词、回答或云端令牌。

```sh
swift run --sdk /Library/Developer/CommandLineTools/SDKs/MacOSX26.5.sdk AgentChecks
./scripts/check.sh
./scripts/build.sh
```

`AgentChecks --live-read`额外读取当前已登录Codex和运行中的WorkBuddy；不创建模型任务。真实运行检查和界面证据保留在本机`verification/agents/`。
