安装功能保存与接入验证与限制源码来源

安装与第一次使用

适用 Apple 芯片 Mac（M 系列），macOS 15 或更高版本。首次安装：打开 DMG，把“一切在岛”拖到 Applications（应用程序）。已有旧版时先退出并备份旧应用与数据，体验确认后再决定替换。正式候选沿用原应用身份与个人数据，不要同时启动两份正式应用。名为“一切在岛体验版”的独立预览使用临时合成任务，不作为日常数据长期保存。

应用后台运行，不必常驻程序坞。鼠标移入屏幕顶部灵动岛；展开后只用右上角齿轮打开当前栏目的设置。设置和小岛同时可用；打开或关闭设置不改变小岛的展开与锁定状态。首次飞书连接需要你本人登录并同意授权。已保存的有效连接会恢复，手动暂停状态会保留。

本包使用本地签名，未做 Apple Developer ID 签名或公证。如果 macOS 拦截，请在系统设置“隐私与安全性”中查看提示并按本人判断允许打开；不需要关闭 Gatekeeper 或系统安全保护。

这一版怎样用

整体形态

内屏和外接屏统一使用悬浮胶囊，不再提供刘海方案或形态选择。有摄像头的内屏保留顶部避让，入口感应区不延伸到两侧菜单栏。四个同级入口：消息、Agent、待办、中台。切换栏目和消息详情保持同一大小，内容过长时在内部滚动。

两种交互

外观与交互 → 鼠标移入，可选完整展开，或先露出胶囊再点击展开。完整展开会连续进入面板；胶囊预览保留较慢下滑。未锁定时空闲移开即收起，输入和菜单操作时保留展开；鼠标静止时保持稳定。展开面板的齿轮左侧有小锁：锁定后无论鼠标移到哪里都保持展开，解锁后恢复原有自动收起规则。

连接自己的飞书

点击「连接飞书」，在飞书页面登录并同意相应用途的授权，即可回到应用使用。日历只读取日程，消息按你的规则提醒。无需创建应用，也不用选择本机配置。每位使用者授权自己的账号，安装包不携带发布者的登录状态。旧版已连接账号可以继续使用。

统一会话管理

私聊与群聊在会话例外列表中统一管理，可搜索并直接设置提醒方式。旧关注迁移为单独提醒，旧屏蔽迁移为静音。保留免打扰、未读校验与消息去重，不改变飞书已读状态。

桌面弹幕

独立开关、字号、速度、文字与背景配色、气泡皮肤。设置内有合成预览。长消息完整保留在岛内阅读；短消息可同时使用透明桌面弹幕。

待办与长期历史

在灵动岛输入后按回车或加号确认，新待办置顶，并默认在20分钟后提醒，可在编辑中调整或关闭。完成后显示对勾，再进入可折叠的已完成组，正文保持正常显示；可单条或整组归档。设置中的完成记录按日期分组，可选今天、本周或全部并搜索；点“重新打开”可移回待办，旧提醒关闭。删除任务可从最近删除恢复，完成、归档与删除分别处理。任务与完成记录长期保存。完成行可直接查看完整正文与补充说明；复制单条或本周记录只包含所选完成记录。

提醒与结算

普通待办支持具体时间、多次和重复提醒；截止时间独立设置。灵动岛提醒与屏幕动效可选，完成时可选标记完成或对勾鼓励，两种方式均保留完整文字；休息提醒在单独的设置页管理。不同来源的屏幕提醒按顺序展示，锁屏时保留已经排队的提醒，解锁后继续。日程提醒不会切走正在编辑的待办。休息页中的其他计划提醒直接显示，各自独立开关。

Agent 状态

沿用 Codex、Claude、WorkBuddy 适配器，展示实际取得的状态与额度。点“接入Agent”可复制通用提示词，由工具写回本机状态文件；是否支持持续监测取决于工具实际提供的能力。监测与岛内显示独立，岛内最多三个。点击上下箭头后，设置整行与岛内显示同步移动；隐藏项排在列表末尾。

Agent 完成提醒

以短暂胶囊提示显示状态，多个工具的提示排队显示。监测到的运行会话全部结束并稳定20秒后合并提醒一次；会话暂时漏读不会当成完成。“本轮工作已结束”指运行轮次结束，不是待办数量。不在此输入任务、传文档或调用 Agent 处理材料。WorkBuddy优先显示剩余积分，百分比作为辅助；上次记录、未知与读取失败分别说明，不填造数字。

中台与快捷轮盘

在设置的中台页选择及排序岛内卡片。快捷入口独立配置：默认八个中台入口，也可拖入常用应用、灵动岛设置或自定义 HTTPS 链接。可录制自己的快捷键，默认 Control + Option + 空格；设置中也可点“试开轮盘”。Esc、再次按快捷键或点击外部关闭；点击轮盘中央取消。

外观与交互

保留主题和两种鼠标移入方式；设置中不再提供自动、刘海或形态切换。皮肤提供胶囊、展开与设置实时预览，点选立即生效。显示屏与冲屏素材分开管理；预览可播放、停止和切换，不触发桌面提醒。休息提醒在“休息提醒”设置页，Agent完成提醒在“Agent状态”设置页。

功能精简

不再注册材料处理、给 AI 派任务或独立云归档入口，不启动旧 Dot 任务端口或隧道。旧材料和结果文件保留；原有待办沿用同一工作区。

保存、迁移与 Agent 读取

沿用原应用身份与本机工作区。待办、完成记录和提醒写入本机私有目录，采用原子保存。旧版未完成却已归档的任务单独显示，可移回列表，不计入已完成统计。旧完成任务缺少时间时标记“旧记录 · 完成时间未记录”，不补造日期。保留旧版数据迁移，移除手动导入入口；原文件不改动。

历史可逐项永久删除，必须确认；未归档的任务保留，最后一条记录删除后移除对应的已完成归档。删除不会删除飞书日程。完成记录支持复制单条、本周记录和JSON导出，复制内容包含原文与完成时间，不混入未完成事项或额外提示词。你主动导出并交给 Agent 后，它才能据此生成日报或周报。导出不会自动发送给外部服务。

自定义 Agent 只读取你在设置中选择的 JSON 文件。支持任务 sessions、百分比额度 quotas，以及仅有积分或数值的 metrics；可以只提供实际能够获取的字段。面板可导出接入示例，不执行脚本、不主动派发任务。Agent配置读取失败时保留原配置并停止覆盖；设置页可导出原配置、导入修复后的配置或重新读取。导入前会自动保留原配置副本。

飞书消息正文与中台卡片内容只在内存中使用。包内不包含你的聊天、凭据、工作材料或结果。中台沿用独立授权组件；浏览器只可能用于本人授权或打开所选链接，不承担设置面板。

待办与飞书日程

普通待办在岛内添加、编辑和勾选完成。提醒可直接选择多个具体时间，或设定重复间隔，完成后停止。设置页用于选择默认提醒效果、查看和复制完成记录。

在“设置 → 待办 → 飞书日历”点击“连接飞书”，在飞书页面登录并同意只读授权，回到应用自动同步本人主日历未来 30 天的日程。无需创建应用或选择本机配置。已连接后点击“立即同步”检查最新日程。飞书日程使用独立卡片，默认提前1天和提前15分钟提醒；每张卡片可增加、调整或关闭个人提醒。已经错过的提醒不会补发。应用每分钟同步，也会在返回时检查更新。

点击“新建日程”打开飞书日历，在飞书中填写主题、时间与参与人并保存；回到岛上后同步。点击“在飞书中查看”打开原日程。改期后保留自定义提醒间隔并重新计算时间；取消或移出同步范围后停止提醒。日历同步失败或账号变化时暂停日程提醒，重新同步成功后恢复。普通待办写回飞书的旧流程及其本机关联字段已删除，本应用不创建、修改、删除远程日程，也不发送邀请。

快捷轮盘与配色

轻按快捷键唤出透明圆盘，鼠标滑出目标方向的外圈即可打开；也可以按住快捷键，滑向入口后松开快捷键打开。停在入口上会高亮，直接点击也能打开。按住快捷键时，滑回中央再松开即可取消；点击中央、按 Esc 或再按快捷键也可关闭。八个默认入口：首页、OKR、资料、数据、异常项、应用、Skill、审批。前往“中台 → 快捷入口”，把右侧的入口拖到左侧方向；拖动左侧两行可换位，也可用每行的菜单更换。连接中台后可搜索本人首页的常用应用，灵动岛设置也能放入轮盘。

工作计划卡片只显示“工作计划”一个标题和计划正文。弹幕自定义配色中，点击色块直接选色；“显示背景”和“显示边线”可以分别关闭，预览满意后点“应用配色”。“中国色”打开 zhongguose.com。

打开飞书会话使用对应的 Open Chat ID。电脑里的飞书仍需登录有权查看该会话的账号；此操作不会发送消息或替你加入会话。

本轮变化与验证边界

build86 增加滑出外圈与松开快捷键两种打开方式，保留点击；148 项快捷轮盘合成检查通过。build85 的会话跳转已由本人实际确认能进入正确聊天。新的滑动手感仍需实际鼠标使用确认，不能用合成检查代替。

build84 修复「完整展开」时向上移到刘海区域会立即缩回的问题。鼠标停在刘海中央或展开面板内会保持展开，移到两侧菜单栏或离开面板则收起；「先露出胶囊，点击展开」保持原来的操作。

build83 修复打开飞书会话时的回调崩溃；快查不再等待整批慢会话完成。长消息支持完整分页弹幕，岛内消息保持独立外观。日程结束、取消或删除后会在时间刷新或成功同步时移除；同步失败保留上次快照并暂停提醒。

待办编辑用月日与时间，完整日期保留在记录里。完成记录可折叠、滚动。中台岛内只展示所选卡片，隐藏创建人、创建时间；快捷打开仍可从快捷键和设置使用。联系人提醒按钮直接显示规则；自定义弹幕配色支持颜色代码、复制和即时预览，点击「应用配色」保存。

合成检查覆盖后台会话回调、慢会话调度、长文完整性、日程过期与取消、历史记录和只读授权边界。真实新消息的到达速度、多日连续运行、其他同事首次授权和不同 Mac 刘海观感需要各自在实际设备确认。

适用于 Apple 芯片 Mac、macOS 15 或更高版本。本机旧数据和有效连接保留。安装与服务发布的最终事实见随源码提供的本轮工作记录；开发分支同步不等于 main 合并。
