飞书工作岛返回安装页

Agent 操作指南

用于协助当前使用者安装、连接和调整自己的工作岛。此页不包含令牌，也不授予访问权限。以使用者本次要求、客户端工具规则及当前界面为准。

1. 先检查，避免重复安装或配对

适用 Apple M 系列 Mac、macOS 15 或更新版本，当前包为 0.8.0 build 46。通过本人已登录的浏览器访问本安装入口，下载 DMG，对照 SHA-256。只安装包内工作岛应用，Applications 是拖入目标。

先检查 /Applications 和 ~/Applications 中是否已有“飞书工作岛.app”，以及其运行状态。旧安装可能仍叫“飞书工作岛预览版.app”；更新前先退出旧版，不同时启动两份。账号与工作区沿用原身份。已有相同版本无需替换；已有活动任务先保留，不覆盖运行中的程序、不清空工作区、不重置账号或接收规则。安装包未完成 Apple Developer ID 签名公证，遵循系统的来源确认流程，不关闭系统保护。

2. 连接本人的飞书和 AI

从运行中的灵动岛点齿轮，打开完整工作台的“账号与消息”；本机连接页默认地址 http://127.0.0.1:18766/ 。该地址仅在使用者自己的 Mac 可达；不要把云端 Agent 的 localhost 当作这台 Mac。端口被占用时以应用打开的地址为准。

在“账号与消息”点“连接自己的飞书”，按当前界面分别完成消息接收和材料归档授权。公司入口代管应用配置，各人使用自己的身份；不填写开发者密钥、不取其他浏览器 Cookie。扫码、系统确认和新权限按本人确认流程处理。已有正常接收保持原配置。

优先使用本人已有的 AI 工具。WorkBuddy使用本人已安装并登录客户端的官方本机运行组件，在后台处理并回到本项目待办；Codex 依赖本机本人登录；豆包浏览器路径依赖本人已登录的服务与 ego-browser。Dot 先核对当前项目是否已配对、私人插件和隧道是否可用、任务通知是否有有效订阅。仅配对成功不能报告自动处理完成；不能使用开发者的隧道、令牌或其他项目。新的项目访问需要本人确认。不要创建重复的 Dot 自动任务。

诊断可读取 /api/dot-diagnostics 的有效订阅、续订时间和计数；只输出脱敏状态，不输出令牌、回调地址、消息正文、项目材料。不要调用会重新授权或停用接收的操作来“检查”。

可选：WorkBuddy 自动积分

在工作台“Agent接入”开启每日免费领取。只连接本人已登录的WorkBuddy；macOS辅助功能列表中的组件叫WorkBuddyCheckin，新的访问由本人确认，系统身份验证由本人完成。工作岛运行时每天本机9:10检查，睡眠/退出后补查；无需创建Codex定时任务。只领取已知免费积分，不购买或邀请。已经领取就跳过，结果不明不盲目重复点。这个安装包不包含开发者的登录、开关或签到记录。

3. 定制首页、数据和外观

按本人要求调整虚实中台首页或数据页：使用本人的 virxact MCP，先 get_spec 与 get_page，在既有个人页面上修改；字段按 list_fields 核对，遵守 preview_page 等工具的真实格式与保存流程。只改本人授权的范围，不把读取业务数据变成写入底表。

灵动岛内显示哪些中台卡片，在工作台“虚实中台”或岛内“中台”页选择；不要把修改整个中台页面当作只调整岛内卡片。

  • 外观：工作台“账号与消息”中的“接入 Agent”复制 /mcp 连接，30 分钟有效，只允许 read_appearance、update_appearance 白名单。确认 saved=true 才表示保存。不能修改核心接收、授权或过滤。
  • 项目任务：工作台“处理与归档”中的“接入Agent”复制 /mcp/workspace，限定当时当前项目已有任务快照，30 分钟、锁屏撤销。与外观接口分开。
  • Dot：独立的 /mcp/dot 长期项目配对，必须经过本人的项目确认。此页面及“复制交给 Agent”按钮不会代为发放任何凭据。

4. 可选网页收录

扩展已包含在应用内：Contents/Resources/BrowserBridge/chrome-reader。先确认安装路径，再用 Finder“显示包内容”找到该目录。不要从他人资料目录复制扩展或登录数据。按照浏览器允许的方式，在 Chrome 或 ego 的扩展管理页加载该目录；需要本人操作的受限步骤，明确告诉他点哪里。

在工作台“处理与归档”开启“接收Chrome当前网页”。扩展只在本人点击时读取当前页面，先预览确认再送本机草稿。它不读取 Cookie，不扫描其他标签页，不自动把页面交给 AI。应用更新后在扩展管理页刷新；若应用位置改变，重新选择新路径。

5. 实际验证，报告边界

外观、显示屏和快捷键统一放在“外观与交互”；待办提醒和循环计划在“待办与提醒”，个人视频在“冲屏素材”。桌面短消息弹幕是独立开关，只显示符合既有提醒规则的单行短正文，长文保留岛内；不得为了让试播出现而改账号、屏蔽或免打扰规则。冲屏素材先用普通窗口预览，不擅自用全屏现场试播验收。

得到对应操作授权后，用明确的合成文字及附件测试一次：送入工作岛 → 按需交给 AI → 自动归档飞书 → 原任务取得文档链接。直接归档无需调用 AI。先查本次测试任务避免重复提交，若调用 AI，核对该任务 succeeded；归档则核对 archive.state=succeeded、回读成功及结果链接，不读取其他项目或真实聊天。结束时清除本次合成提醒；不做全屏遮罩、不退出飞书。

分别报告安装、本人授权、AI 回传、归档及连接续期的实际状态。开发者的验收不替代当前同事账号或设备的验收。使用者要的是日常项目，不能一直停在测试项目。
