一切在岛返回安装页

接入与协助说明

0.9.0 build 52。中台发布名为“一切在岛”，安装包内的应用名为“你的飞包”。宰治和柚子共同发布。

安装与连接

使用 Apple M 系列 Mac、macOS 15 或更高版本。从本人已登录的公司入口下载 DMG 安装包，可对照 SHA-256。更新前先退出旧版，在原安装位置替换，保留工作区与账号配置。扫码、授权和系统身份验证须本人完成。

设置在独立原生 Mac 窗口中打开。灵动岛展开后点齿轮，选择“飞书消息”连接自己的账号；有效连接会恢复。当前版本不使用本机浏览器工作台。

Agent 只展示状态

在“Agent 状态”选择需要监测与展示的来源，岛内最多三个。上下箭头同步移动设置整行与岛内顺序；隐藏展示不会断开监测。实际状态、额度或积分取决于来源能够提供什么，未知数据不表示零。

自定义 Agent 选择本人本机的 JSON 状态文件，可从界面导出格式示例。仅提供实际可读的 sessions、quotas 或 metrics 字段。此页不提供令牌，不授予任何访问权限；当前产品不提供 AI 派单、项目 MCP、Dot 隧道、材料传输或网页收录扩展。

待办与历史

待办完成后可折叠、归档，历史按日期保留。本人主动导出版本化 JSON 后，才交给 Agent 生成日报或周报；应用不会自动发送这些数据。旧记录缺少完成时间时不能补造日期。

中台与外观

中台使用本人的独立授权，卡片选择和八方向轮盘在“中台”管理。主题、形态、两种悬浮方式与冲屏素材在“外观与交互”管理。材料先在普通窗口中预览。

验证边界

协助时先检查现有安装、运行状态和使用者的具体目标。只在授权范围内操作，不覆盖运行中的应用，不读取真实聊天作为测试，不修改飞书已读，不复制别人的凭据。使用者的实际登录、真实新消息和多日运行，需要对应设备上的实际证据。
