四个入口，一个灵动岛

少切几个窗口。
事情就在眼前。

鼠标移入即可展开，也可以先预览、点击再展开。移开后自动收起。

  1. 01

    飞书消息

    私聊与群聊，一处管理

    首次引导本人授权，之后恢复有效连接。字号、速度、配色与气泡独立调整；长消息在岛内完整阅读。

  2. 02

    Agent 状态

    进度、额度与完成提醒

    展示实际可获取的数据，支持自定义状态来源。岛内最多显示三个，点击上下箭头，设置整行与岛内顺序一起移动。

  3. 03

    待办

    完成、折叠、归档与历史

    未完成优先，完成后划线。按次或按周期提醒，轻提示与冲屏可选；按日期保留完成记录，可主动导出给 Agent 总结。

  4. 04

    中台

    常用卡片与快捷信号轮盘

    八个方向放八个常用入口，点击或拖动打开。主栏可隐藏，配置仍保留。

主题、形态、两种悬浮模式与冲屏素材，都在“外观与交互”中统一设置。

怎么打开设置？+

将鼠标移到 Mac 顶部灵动岛，展开后点击齿轮。五个设置模块在独立原生窗口中配置，不用打开浏览器工作台。

查看功能说明
Agent 能做什么？+

展示实际可获取的状态、额度或积分，并在完成时提醒。自定义 Agent 可接本机 JSON 状态文件；当前版本在岛内不下发任务或传文档。

数据和使用范围？+

待办与历史保存在本人 Mac，飞书消息正文只在内存中使用。每位同事连接自己的账号。真实授权、新消息类别、Agent 来源和多日运行，按各人的设备实际核对。
