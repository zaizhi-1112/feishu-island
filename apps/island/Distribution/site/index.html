下载 Mac 版 查看安装方法

下载已开始。打开 DMG，将“一切在岛”拖入应用程序。

四个入口，一个灵动岛

常用信息集中在一起，按自己的习惯选择和调整。

飞书消息

私聊与群聊，一处管理

首次引导本人授权，之后恢复有效连接。字号、速度、配色与气泡独立调整；长消息在岛内完整阅读。

Agent 状态

进度、额度与完成提醒

展示实际可获取的数据，支持自定义状态来源。岛内最多显示 3 个；点击上下箭头，设置整行与岛内顺序同步调整。

待办

完成、折叠、归档与历史

未完成优先，完成后划线。按次或按周期提醒，轻提示与冲屏可选；按日期保留完成记录，可主动导出给 Agent 总结。

中台

常用卡片与快捷信号轮盘

8 个方向放 8 个常用入口，点击或拖动打开。主栏可隐藏，配置仍保留。

主题、形态、两种悬浮模式与冲屏素材，都在“外观与交互”中统一设置。

安装与连接

安装包内的应用名为“一切在岛”，沿用原应用身份与个人数据。

  1. 1

    下载并打开 DMG

    适用 Apple M 系列 Mac，macOS 15 或更高版本。

  2. 2

    拖入应用程序

    首次安装拖入 Applications。更新前先退出旧版，安装后将旧版“你的飞包”移到废纸篓。

  3. 3

    连接本人飞书

    从灵动岛打开原生设置，按提示完成本人授权；已有有效连接自动恢复。

当前包为本地签名，尚未完成 Apple 公证。遇到来源提示时，使用 macOS“隐私与安全性”中的确认入口。Intel Mac 和 Windows 暂不提供安装包。

常见问题

怎么打开设置？

将鼠标移到 Mac 顶部灵动岛，展开后点击齿轮。五个设置模块在独立原生窗口中配置，不用打开浏览器工作台。

查看功能说明
Agent 能做什么？

展示实际可获取的状态、额度或积分，并在完成时提醒。自定义 Agent 可接本机 JSON 状态文件；当前版本在岛内不下发任务或传文档。

查看接入与协助说明
数据和使用范围？

待办与历史保存在本人 Mac，飞书消息正文只在内存中使用。每位同事连接自己的账号。真实授权、新消息类别、Agent 来源和多日运行，按各人的设备实际核对。
