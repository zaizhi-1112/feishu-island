安装与第一次使用

适用 Apple 芯片 Mac（M 系列），macOS 15 或更高版本。首次安装：打开 DMG，把“你的飞包”拖到 Applications（应用程序）。已装旧版：先正常退出旧版，将新版放回原安装位置替换，避免留下两份同名应用；然后再打开新版。

应用后台运行，不必常驻程序坞。鼠标移入屏幕顶部灵动岛；展开后的齿轮打开独立设置窗口。首次飞书连接需要你本人登录并同意授权。已保存的有效连接会恢复，手动暂停状态会保留。

本包使用本地签名，未做 Apple Developer ID 签名或公证。如果 macOS 拦截，请在系统设置“隐私与安全性”中查看提示并按本人判断允许打开；不需要关闭 Gatekeeper 或系统安全保护。

这一版怎样用

整体形态

顶部保留宰治版本的刘海布局；展开界面、主题画廊和原生设置沿用佑哥的设计。四个同级入口：消息、Agent、待办、中台。

两种交互

外观与交互 → 鼠标移入，可选完整展开，或先预览再点击展开。默认完整展开；移开自动收起。收纳提示边缘窄于主体。

飞书自动连接

新安装会打开独立授权窗口。登录与同意授权须本人完成；有效连接后自动恢复。网络失败只重试，确认授权过期后才提示重新登录。

统一会话管理

私聊与群聊集中管理。旧关注迁移为单独提醒，旧屏蔽迁移为静音。保留免打扰、未读校验与消息去重，不改变飞书已读状态。

桌面弹幕

独立开关、字号、速度、文字与背景配色、气泡皮肤。设置内有合成预览。长消息完整保留在岛内阅读；短消息可同时使用透明桌面弹幕。

待办与长期历史

未完成在前；完成后划线并移到底部，可逐项折叠到已完成区，归档后进入按日期查看的历史。内容、状态和完成时间长期保存，退出应用不丢失。

提醒与结算

任务支持一次、多次、按间隔提醒与截止时间；习惯提醒支持周期。轻提示与冲屏可选；完成任务可选结算素材。锁屏暂停展示，唤醒不重放所有错过的提醒。

Agent 状态

沿用 Codex、Claude、WorkBuddy 适配器，展示实际取得的状态与额度。自定义 Agent 可选本机 JSON 状态文件。监测与岛内显示独立，岛内最多三个。点击上下箭头后，设置整行与岛内显示同步移动；隐藏项排在列表末尾。

Agent 完成提醒

轻提示或共用素材冲屏；不在此输入任务、传文档或调用 Agent 处理材料。未知额度明确显示未知，不填造数字。

中台与 LOL 轮盘

原生八方向轮盘复用 LOLPingYourAI 的选择几何、信号图标与音效。点击或拖动松手打开入口，中心取消。只接快捷启动，不接 Agent、截图或额外后台。

外观与交互

保留主题、形态和两种悬浮偏好，移除独立材质与旧快捷键页面。冲屏素材统一导入、选择和窗口内预览；提醒规则在待办和 Agent 设置。

功能精简

不再注册材料处理、给 AI 派任务或独立云归档入口，不启动旧 Dot 任务端口或隧道。旧材料和结果文件保留；原有待办沿用同一工作区。

保存、迁移与 Agent 读取

沿用原应用身份与本机工作区。待办、完成记录和提醒写入本机私有目录，采用原子保存。旧版未完成却已归档的任务单独显示，可移回列表，不计入已完成统计。旧完成任务缺少时间时标记“旧记录 · 完成时间未记录”，不补造日期。佑哥旧待办可在待办设置中选择原数据目录导入；原文件不改动，重复导入不会重复生成任务。

待办历史提供版本化 JSON 导出（schema_version = 1），包含原文、完成状态、完成时间与历史时间未知标记。你主动导出并交给 Agent 后，它才能据此生成日报或周报。导出不会自动发送给外部服务。

自定义 Agent 只读取你在设置中选择的 JSON 文件。支持任务 sessions、百分比额度 quotas，以及仅有积分或数值的 metrics；可以只提供实际能够获取的字段。面板可导出接入示例，不执行脚本、不主动派发任务。

飞书消息正文与中台卡片内容只在内存中使用。包内不包含你的聊天、凭据、工作材料或结果。中台沿用独立授权组件；浏览器只可能用于本人授权或打开所选链接，不承担设置面板。

实际验证与使用边界

  • 完整编译通过；1,149 条融合回归、703 条 Agent 检查、49 条飞书专项检查通过。
  • 104 条外壳、49 条导航、85 条旧待办兼容、57 条中台轮盘模型、30 条统一产品检查（含12条悬浮取消回归）通过。
  • 12 项打包单测通过，缺失必需主题资源、额外文件或个人数据会拒绝打包。
  • 五个原生设置页面已渲染核对；隔离窗口实际点验新增待办、完成、归档与按日期查看历史。
  • 离线说明已检查桌面与 390px 窄屏、字号切换与目录跳转；正文无横向溢出。

本轮没有替你登录、同意新授权、发送飞书消息或读取真实聊天。真实飞书首次登录、不同 Agent 当前账号额度、真人悬停手感和多日稳定运行，需要在实际使用时继续确认。旧版不会被本次打包自动退出或覆盖。

目前打包目标为 Apple 芯片 Mac。Intel Mac、其他同事账号与设备及 Apple 公证不包含在本轮已验证范围。
