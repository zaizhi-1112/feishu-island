## 临时待办与定时提醒（0.7.0）

展开面板顶部有飞书、Agent、待办三个固定图标。任意模块下都能拖入文字、网页链接或普通文件，直接创建待办；一次拖入的多个文件归到同一条。待办页也能直接输入。保存提示提供修改与撤销，查看不算完成，支持完成后恢复、延后提醒和单独关闭提醒。

默认20分钟后提醒；原生齿轮与网页“待办提醒”可修改默认分钟数及提示音，只影响以后新建的事项。到期露出第二阶段胶囊约5秒，轻响一次，以橙色标记。已经打开的内容不被抢走；多条合并，飞书与Agent提示排队，0.7.3起，待办入口只提示尚未查看的新到期事件，进入后清除；事项列表中的到期状态继续保留，直到完成、延后或关闭提醒。

事项、设置、提醒送达状态原子保存于模块独立目录，附件保存副本，不跟随原文件更新。重启后仍保留。睡眠期间错过的提醒在唤醒后合并补一次，退出期间的在下次启动补一次；已提示过的不会因重启重复响铃。应用退出时无法即时提示。暂不支持文件夹、文件替身、飞书任务同步、重复任务或AI处理。

构建并打开独立预览：

```sh
bash scripts/build.sh
bash scripts/package-todo-preview.sh
bash scripts/todo-preview.sh
```

正式版待办数据位于`~/Library/Application Support/local.youzi.island/Modules/local.youzi.island.todos/`。预览包在`verification/todos/柚子岛待办预览.app`，有独立应用标识、待办数据目录和网页设置端口，不启动真实飞书与Agent读取器。预览数据默认位于`~/Library/Application Support/local.youzi.island.todo-preview/Modules/local.youzi.island.todos/`，升级时保留在原处。验证工具须通过`--todo-test-root`指定另外的测试目录，测试结果不写入预览的正常待办库。

逻辑检查：`swift run --sdk /Library/Developer/CommandLineTools/SDKs/MacOSX26.5.sdk TodoChecks`。真实窗口测试在独立预览中使用`--todo-preview --todo-test-root <独立测试目录> --todo-capture <证据目录>`；其睡眠和唤醒是模拟事件，不冒充真实睡眠或物理插拔测试。验收说明见`verification/todos/验收记录.md`。

## 启动与使用

已安装到`~/Applications/柚子岛.app`，双击即可启动；构建副本在`dist/柚子岛.app`。应用常驻菜单栏，不占Dock位置。

桌面提供`~/Desktop/柚子岛.app`原生Finder替身，指向上述已安装应用；后续在原位置升级应用后仍可继续使用。图标采用银白连续圆角底、黑色胶囊、青蓝流线和薄荷色状态点，参考[Apple应用图标规范](https://developer.apple.com/design/human-interface-guidelines/app-icons)及[Dynamic Island设计案例](https://developer.apple.com/news/?id=mis6swzt)。原生绘制源在`scripts/generate-app-icon.swift`，生成`Resources/AppIcon.png`、完整尺寸的`AppIcon.iconset`及打包用`AppIcon.icns`；现有构建脚本会自动装入图标。重建图标运行`swift scripts/generate-app-icon.swift`；已安装应用包含图标后，运行`swift scripts/install-desktop-shortcut.swift`即可创建或更新指向相同应用的桌面替身，不覆盖其他桌面项目。

- 无刘海屏幕平时只留下4个逻辑像素高的小边；鼠标移到小边，滑出当前模块的状态胶囊，上沿距屏幕顶边4个逻辑像素。
- 刘海屏幕收起时不再绘制额外黑边，在原生刘海及其下沿保留近透明的鼠标感应区；悬停时在刘海两侧露出状态，与硬件刘海连成一体。
- 点击露出的状态区域，才打开完整面板。悬停多久都不会自动打开完整面板。
- 无刘海屏幕上，第二段胶囊和第三段面板共用4点的顶部间距，展开时沿同一顶边向下生长。首页和示例页采用紧凑排布，面板外部宽度约400点；刘海形态继续保留硬件避让。
- 鼠标离开后缩回顶边；打开“保持展开”后，完整面板会继续留在屏幕上。
- 锁形按钮切换“保持展开”；菜单栏提供收起入口。
- 默认快捷键为`Option + Command + ;`，可在“设置→快捷键与交互”修改。占用冲突会显示提示。
- 展开面板顶部有飞书、Agent、待办三个固定图标，点击即可切换。
- 指针放在展开的主面板内，触控板双指左滑进入下一个面板、右滑返回；顶部图标下的同色细光条提示尚未查看的新事件。
- 菜单栏的胶囊图标提供展开、设置、模块切换和退出入口。

## 飞书消息简版

- 使用本机`~/.local/bin/lark-cli`的默认账号授权，以用户身份只读接收。不替换全局CLI，不自动申请新权限。设置面板随应用在本机运行。
- 默认提醒直接@本人、@所有人、私聊和手动关注会话的新未读消息；尊重飞书免打扰。4类提醒可在网页中分别开关。@所有人单独识别，不冒充@本人。
- 重要消息短暂提示4秒，不显示正文；密集消息合并计数，提示间隔至少12秒。已展开或固定面板时不抢走当前内容。
- “重要”与“最近”展示本次接收的消息，最多保留100条。点击消息看详情，星标关注该会话，“打开会话”交给本机飞书客户端。
- “静音1小时”只暂停提示，继续接收；到期后汇总提醒。静音截止时间和关注的会话ID保存在模块偏好中。
- “10分钟后提醒”是本地提醒，仅本次运行有效；退出应用后不保留。没有保存消息正文或持久聊天历史。
- 岛内查看只改变本地待查看标记，不写飞书已读。打开原会话后，由飞书客户端处理阅读状态。
- 连接异常直接显示在消息页。右上角“…”可查看账号状态、停止接收或重新连接。授权失效时由用户在终端完成`lark-cli auth login`后重连。
- 接收从本轮连接后开始，停止期间、退出期间及启动前的历史消息不回放。轮询延迟受接口和会话数量影响，不能当作飞书全部未读列表。

消息列表、默认规则、CLI兼容调用和第一次点击修复的验收见`verification/feishu-0.3.0/验收记录.md`。

## 网页设置面板

在飞书消息面板底部点击“设置面板”，或在岛内齿轮设置中打开“设置面板”分组。默认地址为`http://127.0.0.1:18766/`；端口被占用时会选用空闲端口，岛内入口会打开实际地址。页面需要柚子岛保持运行。

- 当前可用：接收总开关、@我、@所有人、私聊、关注会话，以及指定联系人、指定群聊和屏蔽规则。选择只改变草稿，点击保存后进入应用；重启后保留。
- 联系人和群聊从当前飞书账号读取，可搜索、多选；联系人默认列出最近聊过的人，搜索结果较多时需缩小关键词；群聊仅显示已加入的群，支持加载更多。界面显示部门或群类型和ID尾号帮助区分同名对象，规则使用稳定ID匹配。
- 每个人或群可设为“全部提醒”“只提醒@我/@所有人”“仅收进最近”；也可单独屏蔽和解除屏蔽。规则顺序为屏蔽优先，其次联系人、群聊、默认规则。自定义规则总数上限100条。
- 屏蔽后，新消息不进入柚子岛列表，也不触发手动稍后提醒；已有记录暂时隐藏，解除屏蔽后恢复显示，屏蔽期间的新消息不补录。联系人屏蔽也适用于其在群里的消息。
- 设置只影响本机柚子岛；飞书免打扰与岛内静音保持原有规则，单独提醒不能绕过。更改规则会更新岛内“重要”列表，但不补弹历史消息；未被屏蔽的手动稍后提醒仍有效。“恢复默认”仅重置默认规则，保留单独设置与屏蔽名单。
- 默认规则预览只展示默认规则的效果；通用设置和其他功能模块仍为预留入口。
- 服务只绑定`127.0.0.1`；校验Host、Origin与保存请求头，无跨域开放；旧版本草稿遇到并发修改会拒绝覆盖。网页接口不返回聊天正文。
- 页面源码在`SettingsWeb/dist/`，构建脚本将其打包进应用；原生桥接在`Sources/IslandShell/Settings/SettingsServer.swift`，飞书选人选群的只读查询在`FeishuDirectory.swift`。以后新增功能应通过独立模块与独立设置接入。

规则功能验收见`verification/settings-0.4.0/`；0.5.0视觉更新与截图见`verification/design-0.5.0/`。

网页与原生界面统一使用细边框卡片和系统字体，强调色随所选皮肤变化。网页支持浅色、深色及跟随系统，左下角可切换；此选择仅保存于当前浏览器。灵动岛保留三段交互，皮肤覆盖完整外轮廓，消息列表、详情、空状态、Agent状态和原生设置使用同一套主题。视觉借鉴AIHOT主题页，保留柚子岛自己的布局、标识与功能。

## 内屏、外屏与热插拔

默认“自动（优先外接屏）”：有外屏时优先外屏，没有外屏时回到内屏。多块外屏时优先当前主屏中的外屏，否则使用系统列表中的第一块外屏。自动模式只显示一份窗口。

形态默认为“自动”：无刘海屏幕使用独立胶囊，有刘海屏幕让黑色表面贴合硬件刘海。内屏的第二、三段都从屏幕顶边绘制，摄像头区域留空；完整内容按自身高度展开，顶部模块入口使用图标避让摄像头。通过真实屏幕的安全区域判断，不通过屏幕名称猜测。物理刘海本身无法被软件收起来。

设置里也可选择内屏、当前活动屏幕或一块固定显示器。固定显示器使用稳定UUID记忆，断开时回退可用屏幕，重连后恢复。显示器连接、断开、分辨率变化以及唤醒事件都会触发重新定位。

## 构建与验证

当前交付在Apple Silicon Mac、macOS 27.0.1上构建并验证；未做Intel或旧版macOS实机验证。无需安装完整Xcode。

```sh
bash scripts/build.sh
bash scripts/check.sh
bash scripts/check-feishu.sh
```

本机默认SDK路径是`/Library/Developer/CommandLineTools/SDKs/MacOSX26.5.sdk`。可通过`ISLAND_SDK`指定兼容SDK。打包默认Release构建并做本地临时签名。当前包用于本机运行，没有做公开分发公证。

应用退出后可运行真实窗口检查：

```sh
dist/柚子岛.app/Contents/MacOS/YuIsland --self-test
```

检查会启动窗口、展开收起、往返切换三个模块、进入设置，并发送显示器变化及唤醒通知验证重新定位，输出JSON后退出。它不会物理拔插显示器，也不会真的让Mac睡眠。另一个实例已运行时会提示先退出并返回错误码2，不会误报通过。

基础版验收在`verification/验收记录.md`，三段交互的验收在`verification/edge-dock/验收记录.md`。逻辑检查覆盖模块隔离、三段交互和飞书规则等关键场景。无需授予屏幕录制、辅助功能、网络账户或通知权限即可使用这个外壳。

## 添加模块

1. 将`Examples/MyModule.swift`复制到`Sources/IslandShell/`，使用唯一且长期不变的模块ID。
2. 在`IslandHost.configuration()`中增加`host.register(MyModule.info) { MyModule(context: $0) }`。
3. 在模块的`makeConfiguration()`中提供展开页和两侧胶囊内容。共用外壳、显示策略、设置和动画。
4. 用`context.defaults`存小型状态，`context.containerURL`存文件，避免模块互相覆盖数据。
5. 默认切走就卸载；需要后台持续工作的模块用`.stayResident`，并正确处理生命周期与取消。

`Examples/MyModule.swift`仅作为开发参考，不注册到产品界面。未来音乐、剪贴板、提醒等功能应作为独立模块接入，并按功能所需单独处理权限。

源码：`Sources/IslandShell`是产品壳，`Sources/YuIsland/main.swift`是应用入口，`Vendor/OpenNook`是固定版本的上游核心库。来源、许可与兼容补丁见`Vendor/OpenNook/UPSTREAM.md`。

飞书接收器、时钟校准和相关测试改编自用户提供的源码包，仅用于本机个人融合；来源说明见`Sources/IslandShell/Feishu/SOURCE.md`。
