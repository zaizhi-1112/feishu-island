# 弹幕来源与修改

复用本仓库 apps/danmu/Sources/Message.swift、Overlay.swift 和 scripts/AppearanceMCP.swift（原飞书弹幕 0.7.1）。原副本保留，不改变旧版构建依赖。

融合版增加不上屏的小画布和手动时钟测试入口、窗口/定时器释放、边框绘制、同一接收事件分发、本机外观保存 ACK。MCP 只开放原生渲染实际支持的外观字段，不开放网页布局、历史显示、消息、账号或核心参数。

这是受控副本，修复时应核对原实现；两处不自动同步。来源和授权边界见根 docs/来源与许可.md。

2026-10-20：融合副本增加长卡片的上一页/下一页、暂停/自动和读完；仅 360×32 以内的独立非激活页脚面板接收点击，桌面层继续透明穿透。手动分页冻结当前页；恢复自动重置当前页阅读时间。发送者标签在 FeishuMessage.danmuText 去重，原副本不变。

最新约定：长短消息均走实际 Nook 阅读界面。桌面渲染副本只保留历史与隐藏合成检查用途，不再用于融合版运行时消息展示。
