真实系统提示

在 macOS 26.4.1（25E253），从浏览器下载带隔离标记的 DMG，复制应用并首次打开，实测出现“未打开‘一切在岛’”：Apple 无法验证是否包含恶意软件。两个按钮为“完成”和“移到废纸篓”。关闭提示后，隐私与安全性的安全性区域显示“已阻止‘一切在岛’以保护 Mac”，按钮为“仍要打开”。

测试覆盖首次拦截及系统设置按钮的位置。未代点“仍要打开”，未改变 Gatekeeper 或移除下载隔离属性；系统放行与身份验证由使用者本人完成。不同 macOS 版本的文字可能略有不同。

Apple 官方说明解释首次尝试打开之后的处理步骤。左图为实测拦截，右图为设置位置示意，未公开本机其他安全配置。

六步偏好设置

  1. 完整展开，或先露出胶囊再点击；在预览小岛上实际移入和点击。
  2. 深色、浅色、跟随系统，切换即时生效。
  3. 飞书消息与日历按需独立授权，复用现有授权流程。
  4. 选择桌面弹幕开关及文字、气泡样式，窗口内可预览。
  5. 新待办与日程的提醒方式：岛内轻提醒、猫咪、瑞克，预览留在窗口内。
  6. 选择 Codex、Claude Code、WorkBuddy、DeepSeek Harness；DeepSeek 使用官方鲸鱼图标与蓝色，显示账户余额。

新安装未选择的 Agent 不会读取；跳过后重启保持原选择。老用户升级不重置设置，不强制启动引导；设置底部提供“重新体验引导”。
