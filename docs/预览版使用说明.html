飞书工作岛 · 融合预览 0.6.0

一份本机飞书接收器，同时供灵动岛列表和可选桌面弹幕使用。消息只在内存，不写飞书已读，不发送消息。

这是独立构建，没有安装、没有加入登录项，也没有替换现有弹幕。首次真实接收与弹幕默认关闭；检测到旧弹幕仍在运行时会拒绝开启新的真实接收，不会关闭旧版。

先看演示真实消息外观 Agent验证事实

先看合成演示

  1. 解压预览包，双击“先看合成演示.command”。由你主动启动独立预览版，演示不会调用飞书账号，也不会替换旧弹幕。
  2. 从岛内或齿轮菜单打开“设置面板”。开启“桌面弹幕”，点“保存设置”后再点“合成消息试播”。这个手动试播才会显示短暂透明弹幕，没有全屏测试背景。
  3. “暂停弹幕”暂停移动和出队；“静音1小时”继续收录但不弹新提示和新弹幕；“停止接收”停止读取并清空待播。开启弹幕不回放列表旧消息。

弹幕沿用重要提醒规则：普通群默认只收录；可在指定群聊选择“全部提醒”，仍尊重飞书免打扰。

用预览版自己的菜单栏退出。从演示切到真实模式，需要你先手动退出预览版再重新打开，不影响旧版程序。

准备好以后，再接真实消息

本轮没有进行真实授权或消息测试。接真实消息前，由你决定何时停用旧版接收。预览版不会替你结束旧程序。

账号配置名默认 feishu-island，CLI 默认指向包内官方工具。用你本人的专用飞书应用完成独立只读配置与授权，再开启接收。可以交给自己的 Agent 检查 CLI、profile 和权限；不要复制别人登录态，不为跑通而扩大权限或修改旧版账号配置。新授权对原令牌的影响需另外核对，本轮没有执行。

换 CLI 路径或账号配置时，设置页会先关闭接收。保存后清空旧账号内存列表与会话规则，再完成新授权。选人选群查询使用同一个 profile，按稳定 ID 匹配。

一个按钮接入外观 Agent

在设置页点“接入 Agent”，把复制内容发给同一台电脑的 Agent，再说你要的外观，不必贴回 JSON。它只支持弹幕文字色、背景色、边框色、字号、圆角和滚动/静态动效，不能改接收、过滤、权限或账号。

连接 30 分钟有效、锁屏撤销，应用退出即失效。本机保存成功才返回 saved=true。不要把临时连接内容发到群里。接口不提供消息内容、网页布局、历史开关或远程执行。

本轮实际验证

70 条融合断言通过：模拟官方 CLI 的消息经过同一个 FeishuStore，进入列表并按规则进入弹幕队列。重复、未知未读重试、已读抑制、屏蔽、暂停、静音、停止晚到、账号切换、设置冲突、MCP 外观边界均有合成覆盖。待播 500、列表 100 的限制保留。

真实渲染器测试只创建不上屏的 640×480 小窗口，核对移动、暂停保持位置、长消息分页全文完整、每页至少 12 秒，以及透明、鼠标穿透、不能取得键盘焦点属性。没有显示不透明全屏背景。

外壳原有 99 项、105 会话接收模拟检查通过。浏览器在合成服务上检查了保存、刷新恢复、暂停、Agent 复制、桌面和窄屏。构建已做本地临时签名，但未安装、未启动原生应用；真实飞书新消息、刘海屏、多屏、休眠与多日运行仍未验收。

本包为 Apple Silicon、macOS 15 及以上目标的本机构建，未做 Developer ID 公证，不承诺另一台电脑免提示运行。
