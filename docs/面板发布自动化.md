# GitHub 源码版本确认约定

以用户 2026-10-19 的纠正为准：项目版本源代码保存到 GitHub；公司网站面板只用于双方同步信息与协作。旧的“自动部署产品网页与 Mac 安装包”范围已撤销。

当前定时任务 automation-2 保持暂停。不得自行恢复。双方真实账号对相同代码、主版本及说明分别同意，才授权把该版本源码合入共同仓库 main；工作分支的提交不等于正式版本合入。

手动执行源码确认流程：
1. 先读 AGENTS.md 与 collab/AGENTS.md。用本人登录的浏览器访问面板，不能代双方投票、代人申请或确认身份。
2. scripts/collab-sync.mjs 使用本机 GitHub 登录读取真实 PR 和检查状态，生成签名请求，经同源页面提交 /collab/runner/sync。本机 ~/.config/feishu-island/runner.json 只含面板 capability，不打印或上传。
3. scripts/collab-envelope.cjs 生成签名 claim 请求，经同源页面领取。验证响应签名，原样保存独立 0600 任务文件。没有任务即结束。
4. scripts/collab-runner.mjs CONFIG JOB REPORT 只接受 target=github-source。核对两人批准的代码、说明、基准和自动检查，使用期望 SHA 合并 GitHub PR，再核对实际 main 提交。
5. 将 REPORT 中 {job,digest,sha,mergeSha,commitUrl,ok:true} 用签名 result 请求写回面板。结果不明先查 GitHub，不能盲目重试。失败保留事实并报告，不冒充已发布。

此流程不构建 Mac 安装包，不自动启动、安装或替换应用，不更新产品网页或协作面板服务。协作面板自身的维护部署另按用户明确授权走 virxact MCP，不属于项目版本确认。GitHub 凭证留在本机，面板不存凭证或飞书消息。

项目历史贡献按双方交接包、许可说明和用户确认补录，不伪造 GitHub 作者、面板操作者或历史开发日期；来源补录时间与原始阶段分别显示。
