重叠的地方怎么取舍

  • 待办只保留一份日常数据。继续用已有工作区，新增“进行中／已完成／已归档”。已完成任务可归档、恢复，不自动清除原文或附件。柚子的独立 Todo 实现保留作参考与合成回归，不再启动第二套提醒。
  • 保持紧凑。沿用当前工作岛高度限制与内部滚动，不套用历史版 400 点内容高度。悬停与离开仍沿用现有交互，子菜单和弹出层的保护一并保留。
  • 设置集中在普通工作台。“Agent 与皮肤”提供主题及监测开关；账号、Dot、归档和中台设置继续使用现有连接。
  • Agent 状态与交给 AI 分开。状态监测默认关闭，开启后只读取选中来源；换皮肤不需要开启监测。Claude 未接通，不显示虚构状态。
  • 保留你指定的应用图标。柚子的图标源文件留在源码历史与资源中，候选包沿用现有蓝绿图标。
