怎么用接通到哪一步Agent 对接验证事实

现在可以直接用

  1. 在顶部灵动岛的工作台点窗口图标，打开独立的“个人工作台”。它是普通可关闭窗口，不会覆盖或锁住桌面。
  2. 填写项目名称，输入记录或处理要求。选“添加附件”可放入图片、Word、PDF或文字文件。截图复制后，在输入框按 ⌘V，也可点“粘贴”。图片显示缩略图，提交前可移除。
  3. “存待办”只保存本机；在“交给谁”选择本机 Codex 或“豆包工作 · 本人已登录网页”，“交给AI”才提交这条文字与图片。材料 Skill 仍作为处理要求，不自动执行脚本。图片最多6张、合计20MB；单张10MB、3200万像素以内，应用会去除图片元数据并缩放到最长2400像素。图片原件不移动。
  4. 在“待办”看处理状态、结果和来源。点“存文档”导出本机文字文档；“存到飞书”通过本人豆包工作伙伴新建个人云文档，并要求中台独立回读任务编号。链接生成与回读成功分开显示。
  5. 同一个项目有了记录后，点“归纳这个项目”。它依据这个项目最近40条任务的文字、已有结果和状态，整理进展、下一步及待确认问题，不自动扫描其他项目或飞书聊天，也不推断未提供的图片内容。

Agent 怎样与这个工作台协作

在独立工作台选好项目，点击唯一的“接入Agent”按钮，会复制可供兼容客户端使用的MCP连接。连接只包含当时这个项目已有的最多40条任务，30分钟有效；锁屏、退出或重新接入会使旧连接失效。不要把连接内容发到群里，它包含短期访问凭证。

Agent可列出共享任务、读取一条任务的文字要求和已有结果，并对内容未变化的任务回传结果。回传成功后结果保存在本机，来源标为“外部Agent回传”，触发岛内完成提醒。已标处理或正在运行的任务不能被覆盖，重复相同回传不会重复提醒。新建的任务不会自动扩大这次共享范围，需要本人重新接入。

这份连接只供同一台电脑上的兼容客户端使用。云端Agent不能直接连接本机127.0.0.1；本轮没有为此开放公网端口。此接口没有文件系统、命令执行、飞书聊天、中台凭据或业务写入工具。图片只提供附件数量，不通过MCP传输图片内容；需要看图时用本机Codex材料处理。Agent若要查询飞书、学习中台或Aily历史，应使用各平台自己的已授权接口，再把确实取得的结果回传；本接口不声称能查询所有平台。

给接手开发者的接口说明

Streamable HTTP JSON-RPC：本机设置端口下的 /mcp/workspace，仅127.0.0.1、Bearer短期凭证、无浏览器Origin。工具：list_project_tasks、read_work_task、submit_work_result。后者须提供任务ID、读取时的digest与结果正文，正文最多60000 UTF-8字节。任务材料、图片ID和要求纳入digest。状态不由Agent随意修改；回传只进入可取结果状态。授权令牌不入Git、说明或日志。

提交中断与恢复

应用在启动豆包提交前，先持久保存“提交结果待核对”。只有明确知道尚未点击发送的失败，才允许直接重试。已有原任务链接就只读取原任务；若中断发生在发送之后、取得链接之前，先在豆包核对并用“关联原任务”保存链接，不重复提交。结果保存到飞书按源任务和结果digest复用导出任务，避免重复建文档。停止等候只终止本机等待，云端任务可能继续。

提醒和连贯性

待办可单独设时间，默认沿用20分钟；完成和到期提醒使用现有灵动岛提示。没有新增全屏弹窗、桌面遮罩或无限后台AI轮询。归纳结果保留来源任务，未完成的内容不写成已完成。项目归纳是本人主动点击的动作，不会自行把公司资料交给外部模型。
