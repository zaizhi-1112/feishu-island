## 证据边界

- 用户要求本机清零后亲自重装；未替本人完成新的飞书授权、新消息到达或多日运行验收。
- 同事账号与不同 Mac 实机尚待体验；数据布局测试采用多种合成结构，不能代表每人的真实授权内容。
- 跨应用按键监听需 macOS 系统授权，由本人处理。鼠标关闭和可见关闭按钮不依赖该权限。
- Finder 拖动复制不能自动启动；新版通过打开安装盘内 App 后点击「安装并开始设置」完成复制和启动。App Translocation 路径也进入此流程。
- 当前安装包仍未 Apple 公证，仅支持 Apple 芯片 Mac、macOS 15+。签名更新不等于公证。
- GitHub 开发分支、安装包和网页发布不等于 main 已合并，本次不代替双人批准。
